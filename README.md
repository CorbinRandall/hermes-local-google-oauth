# Hermes Local Assistant — personal Google connection

This is a personal, locally run connection between [Hermes Agent](https://github.com/NousResearch/hermes-agent) and one Google account. It is not an official Hermes or Google service. This repository contains only the public information needed for Google's OAuth consent screen. It does not contain credentials, email, or calendar data.

After the account owner authorizes access, Hermes can read, organize, and send Gmail messages and read or change Google Calendar data when asked. The Google permissions requested are Gmail read, modify, and send, plus Calendar access.

See the [privacy information](PRIVACY.md) for how this local connection handles Google data. To remove access, revoke “Hermes Local Assistant” in [Google Account third-party connections](https://myaccount.google.com/connections).
