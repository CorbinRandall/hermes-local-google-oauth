# Privacy information for Hermes Local Assistant

This OAuth connection is for the account owner's personal use. The public pages in this repository do not collect Google account data.

When the owner asks Hermes to work with Gmail or Calendar, the local Hermes installation uses Google's APIs to access the authorized account. Google OAuth credentials and tokens are stored on the owner's computer, in the Hermes configuration directory. This repository does not receive or store tokens, messages, or events, and it has no hosted application server.

Hermes may send content to the AI model provider selected in Hermes settings to answer a request. The owner can use a local model to keep that processing on their own computer. This connection does not sell Google user data or use it for advertising.

The owner can revoke access at any time in [Google Account third-party connections](https://myaccount.google.com/connections) and can remove the local Hermes token file. Questions about this personal connection can be sent to the support email shown on Google's consent screen.
